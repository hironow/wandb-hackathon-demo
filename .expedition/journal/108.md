- **Insight**: In Bun workspace monorepos, the lock file (bun.lock) lives at the workspace root, not in individual app directories. Setting docker-compose build context to a subdirectory (e.g. ./apps/local-issues) makes the lock file inaccessible to Dockerfile COPY commands. The standard monorepo Docker pattern is to set build context to the repo root and use dockerfile path to point to the app's Dockerfile.
